# System Charter

**Intent:** Every system I build should feel like it's expressing a value through behavior, not decoration — meaning should live in the rules, not in surface style.

**Constraints (3 rules you will not break):**
1. One input controls the system — never stack multiple unrelated controls onto one piece.
2. No straight-line geometry unless the system is specifically about rigidity or breakage — motion defaults to organic curves.
3. Every visual effect must be tied to a rule, not added purely for polish.

**Tensions (2 things in productive conflict):**
- Control vs. drift — systems that reward precision but punish carelessness
- Restraint vs. expressiveness — saying more with fewer rules, not more rules

**Taste vow:** I refuse to add a second effect just because the first one feels too simple — simplicity that reads clearly beats complexity that needs explaining.

## Template Sketch

- Signal: mouse X position
- Parameter: radius
- Behavior: the ring pulses faster as radius grows
- Readability test: if I move left to right, the ring clearly "breathes" faster within 5 seconds
