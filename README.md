# Reusable Studio Engine

A minimal, reusable Canvas starter template for quickly beginning new interactive projects. Includes HiDPI scaling, an animation loop, and one wired input signal, split across small, single-purpose files.

## How to run locally
Open `index.html` directly in your browser — no build step or server required.

## How to deploy
This project is deployed via GitHub Pages, connected directly to this GitHub repo. Every push to `main` updates the live link automatically.

## How I use this to start projects
When a new assignment starts, I copy this repo as my starting point instead of building a project from scratch. I open the Roadmap first to remind myself of the order I like to work in, then rewrite the System Charter for the specific project — new intent, new constraints — before touching any code. The canvas engine itself (HiDPI setup, input tracking, animation loop) stays as-is as the foundation I build the new system on top of.
